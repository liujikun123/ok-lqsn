# 02 页面地图

> 依据：`demo/session_1122_200929`（963 帧 / 422 次点击 / 约 21 分钟，覆盖第 1~7 周完整剧本）。
> 每一条都来自录制里真实发生过的点击，不是猜的。坐标按 1920×1080。

## 0. 整体流程

```
大厅 → 训练剧本 → 选人(下一步×N) → 开始训练确认 → 器材加成展示 ┐
                                                              │
  ┌──────────────── 每天循环（第N周 周一 → 周日）───────────────┘
  │  每日行动页（枢纽）
  │    ├─ 周中 → 训练 → 训练核心（点技能看编队→决定）→ 结果 → 随机事件
  │    ├─ 周六日 → 出行 → 地点页 → 公园 → 公园子页 → 前往XX → 小游戏/结果
  │    ├─ 商店（有「新品上市」时）→ 买到 / 关闭
  │    └─ 比赛日 → 每日页(VS) → 赛前准备 → 跳过比赛 → MVP → 结算 → 目标达成
  └───────────────────────────────────────────────────────────
                                                              │
  最后一天结束 → 训练评分 → 恭喜获得(PT) → 训练结束 → 回大厅  ┘
```

**关键认知：点一次「训练」不是打一场，而是跑完 7 个「周」，中途不回大厅。**
所以脚本要能连续推进几十屏；把「找不到主界面」当成失败是错的。

## 2. 每日行动页：整周唯一的枢纽

屏上固定：`第N周` `星期X` 精力 `a/b` 六个技能（投射 弹跳 防守 体能 运控 意识）`休息` `训练`。
按天不同会多出：

| 变体 | 额外出现 | 去哪 |
|---|---|---|
| 普通日 | 商店 / 新品上市 | 商店 |
| 周末（周六、日） | **出行** @(1608,937) 或 (1709,929) | 地点页 |
| 比赛日 | **比赛** @(1687,935) + `VS` + `今天` + 对手校名 | 赛前准备 |
| 最后一天 | `1天` | 本周末尾 |

`剩余天数`（7天→6天→…→1天）是倒计时，可用来判断「本周还剩几天」。

## 3. 训练核心页：编队怎么数（玩家 2026-11-22 当面确认）

这是全项目最复杂的一屏，**必须逐个点开才能看到编队**：

| 元素 | 长什么样 | 怎么算 |
|---|---|---|
| 技能胶囊 | 右侧一列 6 个圆角长条，含技能名 + Lv.N | 选中项变深色，上方显示「失败率 N%」 |
| 角标 | 胶囊**右上角**橙色圆底 + 白色小人图标 | **只有带角标的才点开检查**；没角标跳过 |
| 队友 | **球场上站着的角色**，头上有 2~5 字名字标签 | 主力「希雅」不算队友，其余每人 +1 |
| 器材 | 画面中间横排的卡片（鞋 / 篮球 / 板 / 女孩抱金猪…） | 每张 0.5；外框**金光 1**、**彩光 1.5** |
| 决定 | 右下角黄色大按钮 | 选完最优技能后点它开训 |

| 474 | 弹跳 | 2 张（金） | 球队经理、真崎、百目鬼 |

## 5. 按钮语义（凭据 = 录制里点它之后发生了什么）

| 按钮 | 语义 | 凭据 |
|---|---|---|
| 训练 | 消耗精力练一次，进训练核心 | 点完变「决定/失败率」 |

| 确定 | 确认加强训练 | 回每日页 |

| 公园 | 进公园子页 | 点了进「在公园干点什么好呢?」 |
