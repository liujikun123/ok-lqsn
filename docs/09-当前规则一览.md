# 09 当前规则一览（2026-11-23 11:10 版）

> 一句话：**这份是「脚本现在真的会这么做」的清单**，不是理想设计。
> 标 ✅ 配置项 = 改 `config/strategy.yaml` 或任务参数就生效；
> 标 🔒 写死 = 现在写在代码里，改配置没用（要改得动代码）。

---

## 0. 两种资源（先分清，搞混全盘错）

| | 局内「精力」⚡ | 局外「专注」 |
|---|---|---|
| 上限 | 130 | 150（**允许溢出**，见过 202/150） |
| 谁消耗 | 每次训练扣一次 | 每次训练固定扣 30 |
| 怎么回 | 只有两条：局内事件「精力+X」、周末「公园」(野餐 +70 / 划船 +30) | 只能喝药水（小瓶 +30 / 大瓶 +60），**绝不花钻石** |
| 作用 | 决定「今天训练还是出行/休息」 | 只决定「够不够开一次训练」 |

判定靠**上限当指纹**：`b ≥ 145` → 专注；`40 ≤ b ≤ 140` → 精力。⬅ 不能靠位置，会读反。

## 1. 每日行动页：今天干什么（🔒 写死顺序）

```
比赛（有比赛日按钮） > 训练（精力 ≥ 40） > 出行（精力 < 40 且能出行） > 休息 > 兜底点下一步
```

- 「休息」**只推进一天、不补精力**，所以精力不够时优先出行去公园补。
- 周末只剩「出行」时就走出行。
- ✅ `训练精力下限`（默认 40）、`排除地点`（游戏厅）、`专注恢复`（用道具/关闭）、`每轮最多补专注次数`（4）

## 2. 训练核心页：练哪个技能（编队打分）

**打分公式**

```
总分 = 队友数 × 1.0  +  Σ 器材分  ，再 × (1 − 失败率/100)
```

| 项 | 分值 | 说明 | 状态 |
|---|---|---|---|
| 队友 | 1.0 / 人 | 场上站着的都算，**含球队经理、含主训本人** | ✅ `teammate` |
| 器材·普通 | 0.5 | 白边/浅色卡 | ✅ `equipment` |
| 器材·金光 | 1.0 | 金框 | ✅ `equipment_tier.金` |
| 器材·彩光 | 1.5 | 彩框 | ✅ `equipment_tier.彩` |
| 技能等级 | 0 | Lv.1/Lv.2/MAX **不计分**，只读出来打日志 | ✅ `level_bonus` 全 0 |
| 失败率 | 乘法折扣 | 30% → ×0.7；50% → ×0.5 | ✅ `fail_weight: 1.0` |

**同分**：失败率低的优先（🔒 写死）。

**只点右上角带黄色角标的技能**（🔒 写死为「只点带角标的」）。

**主训人员**：不写死名字 —— 判据是「出现在**每个**技能采样结果里的那个名字」，
认出来只写日志「本轮主训人员：X」，**不剔除**（恒在场 = 每项都 +1，不影响排名）。
✅ `resident_ratio: 1.0`

**高风险改练意识**（✅ `force_when_risky`）

```
所有能练技能的失败率都 > 30%  且  本期商店确认没有精力道具  →  改练「意识」
```
只要有一个技能读不到失败率、或本期没进过商店 → 这条不生效，按原排名。

**器材读不到 ≠ 出错**：室内体育馆实测 0 张，室外球场 1 张，随进度解锁。

## 3. 编队采样（读数的时机）

- 点开技能后 **0.4s 起拍、每 0.2s 一帧**，凑够 2 帧失败率 + 2 帧队友名就提前收工。
- 多帧投票（取众数）：防止 OCR 把「百目鬼」+「希雅」粘成「百希雅」。
- **整帧丢弃**的情况：
  - 不像训练核心页（既没技能名、也没失败率/Lv、场上名字 < 2 个）
  - 出现「赛前准备 / 跳过比赛 / 前往比赛 / MVP / 目标达成」← 说明中途切页了

---

## 4. 空槽闸门：选人/笔记/器材没选满（✅ `pick_slots`）

- 检出「金色粗框 + 近白底 + 黄色十字」的空槽 → 说明还有没选的。
- 先点一次「自动选择」试着补满；补不上就 **截图 + 通知 + 暂停，绝不自己开训**。
- ✅ `on_empty: 暂停提示`、`auto_fill_first: true`、`max_auto_fill: 1`

## 5. 确认编队页

- 只点「开始训练」，**不改人、不动笔记/器材**（配人是玩家自己做的）。
- 点按钮按「黄色矩形」定位，不按文字框中心（文字框常偏上 30~50px）。

---

## 6. 行为卡（选 1 个技能）

- 三张卡里挑「看破/终结/连携」这类进攻向的；已选中的保持不动。
- 点「确定」按黄色矩形定位。

## 7. 加强训练（✅ `enhance.strategy: max_bonus`）

- 三选一永远挑加成最大的（+102 > +78 > +48）。

## 8. 随机事件 / 剧情选项

**优先次序（🔒 与出行共用 `_reward_key`）**

| 位次 | 内容 |
|---|---|
| 4 | 笔记 |
| 3 | 技能 / 专属 / 绝技 |
| 2 | 精力（**按缺口截断**，超出上限的部分不算） |
| 1 | 属性 |
| 0 | 零用钱 / 其他 |

- 概率型奖励（「30% 概率 属性+60」）**不要** ✅ `event.reject_probability: true`
- 不能撤销的负面选项不选 ✅ `event.allow_negative_event`（在 plans 里）
- 无数值三选项默认 属性 > 精力 > 金钱（🔒）
- 纯对话没选项 → 点「跳过」

---

## 9. 周末出行（✅ 部分 `trip`，多数 🔒）

- 地点优先级：**笔记 > 技能 > 精力（未溢出）> 属性 > 零钱**
- 「精力未溢出」实现：`有效精力 = min(标签精力, 130 − 当前精力)`，缺口 21 时 +70 与 +30 打平，再比属性
- 公园：先补精力（中间 +30 属性 / 右边 +70 精力）
- ❌ 游戏厅（= 拼图小游戏）一律不去 ✅ `排除地点`

## 10. 商店（✅ `shop`）

**只买两样，其余不碰：**

| 买什么 | 条件 |
|---|---|
| 0 元红包 | 免费 / 0 元 / 红包 |
| 精力药 | **局内精力 < 50** 才有资格买 |

- 每期最多买 2 次（`max_buy_per_run: 2`）；不限价（`stamina_item_max_price: 0`）
- 不分工作日/周末（`stamina_item_only_weekday: false`）
- 顺手记录「这家店卖不卖精力药」→ 给上面「改练意识」用

## 11. 扭蛋（✅ 任务参数）

- 只买名字含「笔记」的（`扭蛋目标关键词`），价格 ≤ 120（`扭蛋最高价`）
- 一局只买一次，买过不再检查

## 12. 炒股小游戏（✅ `stock`）

- 现在一律「随便选」，只求把这三屏（选股→走势→卖出→排名）走完，不看盈亏
- 硬上限 30 步，超过停机等人工

## 13. 周六（✅ `saturday.special_case: false`）

- **不写特殊分支**：有训练就打训练；出行照样先看笔记
- 周六只能练「本次训练人员」的专属技能；这个人的笔记没选到 → 自然走出行，不影响决策
