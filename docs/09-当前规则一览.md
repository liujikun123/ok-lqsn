## 0. 两种资源（先分清，搞混全盘错）

| | 局内「精力」⚡ | 局外「专注」 |
|---|---|---|
| 上限 | 130 | 150（**允许溢出**，见过 202/150） |
| 谁消耗 | 每次训练扣一次 | 每次训练固定扣 30 |
| 怎么回 | 只有两条：局内事件「精力+X」、周末「公园」(野餐 +70 / 划船 +30) | 只能喝药水（小瓶 +30 / 大瓶 +60），**绝不花钻石** |
| 作用 | 决定「今天训练还是出行/休息」 | 只决定「够不够开一次训练」 |

判定靠**上限当指纹**：`b ≥ 145` → 专注；`40 ≤ b ≤ 140` → 精力。⬅ 不能靠位置，会读反。

## 1. 每日行动页：今天干什么（🔒 写死顺序）

```
比赛 > 探出行（看笔记） > 商店（精力<50 或 有新上架；**周日不进**） > 训练（精力≥12） > 出行（精力<12 补精力） > 休息 > 兜底
```

- **精力门槛 40 → 12**（2026-11-23）：以前精力 32 的周六被挡成出行，每周白丢 1 天训练。
  实测每次训练只花 15~25 精力，130 上限足够周一到周六天天练。
- **商店入口（2026-11-23 新接）**：`_do_shop` 早就写好了，但每日页从来没点进去过 →
  整轮没进过店、精力药一颗没买。现在两种时候进店（一天最多一次）：
  ① 精力 < 50；② **商店图标挂着「新品上市」标签**（= 这家店上新了）。
  **周日一律不进**（玩家：周日去公园就能回满，买精力药纯属溢出浪费）。
  ✅ `skip_weekdays: [7]`

- **探出行（2026-11-23 新增）**：只要今天能训练、也有「出行」，就先进出行页扫一眼地点标签。
  有「笔记」→ **直接出行**（笔记 > 训练）；没笔记 → 退回每日页走训练。每天只探一次。
  出行页如果退不出去（点了退出/ESC 仍在原页）→ **永久关闭这条路**，按原顺序走，不卡页。

- 「休息」**只推进一天、不补精力**，所以精力不够时优先出行去公园补。
- 周末只剩「出行」时就走出行。
- ✅ `训练精力下限`（默认 40）、`排除地点`（游戏厅）、`专注恢复`（用道具/关闭）、`每轮最多补专注次数`（4）

## 2. 训练项页：练哪个训练项（训练项打分）

**打分公式**

```
总分 = 队友数 × 权重  +  Σ 器材档位（普 0.5 / 金 1.0 / 彩 1.5），再 × (1 − 失败率/100)
```

| 项 | 分值 | 说明 | 状态 |
|---|---|---|---|
| 队友 | 1.0 / 人 | 场上站着的都算，**含球队经理、含主训本人** | ✅ `teammate` |
| 球队经理 | **2.0 / 人** | **按项概率出现（实测 25.1%），不是常驻**；这帧读到名字才按 2.0 算，没读到就不加 | ✅ `manager_weight: 2.0` |
| 器材·普（未暴击） | 0.5 | 浅奶油黄细框、无外光 | ✅ `equipment_tier.普` |
| 器材·金暴击 | 1.0 | 浓橙金粗框 + 橙色外光晕 | ✅ `equipment_tier.金` |
| 器材·彩暴击 | 1.5 | 环绕整卡的完整彩虹光晕 | ✅ `equipment_tier.彩` |
| 训练项等级 | 0 | Lv.1/Lv.2/MAX **不计分**，只读出来打日志 | ✅ `level_bonus` 全 0 |
| 失败率 | 乘法折扣 | 30% → ×0.7；50% → ×0.5 | ✅ `fail_weight: 1.0` |
| 失败率上限 | **≤30% 允许赌** | 你的原话「失败可以赌一把，收益如果很高，小于 30 都能去」→ 30 以内不排除，按 `收益×(1−失败率)` 排期望；>30% 才踢掉 | ✅ `fail_limit: 30` |
| 意识加权 | **精力 < 30 时 +2** | 意识不耗精力、反而小幅回精力、成功率最高 → 低精力时的「精力泵」 | ✅ `consciousness` |

> **器材按训练项分布**：开局先选 5 个，训练中会分布在不同的训练项里、也可能不出现，
> 所以「这一项摆了几张」是真实差异，按项计分；「普/金/彩」是暴击状态、随机，不按项比。
> 器材上限 5 张（不是 3）。

**同分**：失败率低的优先（🔒 写死）。

**候选池 = 带角标的技能**（🔒 玩家 2026-11-24 12:55：「角标代表有人，没角标的一定没有人」）

| 情况 | 处理 |
|---|---|
| 有角标 | 进候选池，点开读队友 / 器材 / 失败率 |
| 没角标 | 队友恒为 0 → 不点、不采（省时间，也避免误读的名字被当队友抬分） |
| 六项全没角标 | **先当残帧处理**：等 0.5s 重取帧，最多 3 次；3 次仍无才按默认选中项决定（真实对局 575 帧实测 0 例「全无」，见 `docs/16` §7） |
| 角标怎么认 | 全图搜橙色小圆 + 按纵向就近分配，**一对一**（相邻两行不共用同一个角标）；阈值 0.055h |

默认选中项若**有角标**，则先采它且一次都不点（进页面就展开着它的编队，点它会把默认态改成
手动选中、触发二次确认开训，见 `docs/16` §5）。

**主训人员**：不写死名字 —— 判据是「出现在**每个**训练项读数结果里的那个名字」，
认出来只写日志「本轮主训人员：X」，**不剔除**（恒在场 = 每项都 +1，不影响排名）。
✅ `resident_ratio: 1.0`

**高风险改练意识**（✅ `force_when_risky`）

```
所有能练训练项的失败率都 > 30%  且  本期商店确认没有精力道具  →  改练「意识」
```
只要有一个训练项读不到失败率、或本期没进过商店 → 这条不生效，按原排名。

**器材的「普/金/彩」是什么**：局内**熟练度提升后几率的暴击光效**，出现后持续显示到
该项训练结束。玩家原话：「随着训练，在局内它这个器材的熟练度会提升，就会有几率变成
金色和彩色的暴击效果。」暴击了这一项的收益更高，所以按档位计分。

判据：金看**框线最外沿 1~3px 的饱和度**，彩看**整圈光晕的色相构成**
（两者采样位置不同，因为彩卡光晕有厚度）。

| 档位 | 判据 | 实测读数 | 瞬时占比 |
|---|---|---|---|
| 普（未暴击） | 最外沿饱和度 120~165（浅奶油黄细框、无外光） | S 120~165 | 62.9% |
| 金（金暴击） | 最外沿饱和度 ≥185（浓橙金粗框 + 橙光晕） | S 209~225 | 35.8% |
| 彩（彩暴击） | 多圈里 rainbow≥0.30 **且** warm≥0.05 **且** nbig≥3 | rb 0.63~0.94 | 1.3% |
| — | 165~208 | （空档，阈值 185 落这里） | — |

右侧占比是实机帧的**观测比例**，不是卡池分布，也不是器材稀有度 ——
同一件器材既会以普框出现、也会以金/彩 框出现。

**彩的判据为什么要三个条件**：只看「青蓝紫占比」不行 —— 室外球场的**蓝色地板/蓝天
占比是 1.00，比彩卡还高**，会把室外场景每张卡都判成彩。彩虹 = 多色相 + 冷暖共存，
单色背景只有一个色相桶（nbig=1）、暖色为 0：

| 来源 | rainbow | warm | nbig |
|---|---|---|---|
| 彩卡（黄背景 / 蓝背景） | 0.66~0.90 / 0.66~0.81 | 0.08~0.15 / 0.06~0.30 | 4~7 / 3~6 |
| 纯蓝地板 / 纯蓝天 | 1.00 / 0.96~1.00 | **0.00** | **1** |
| 金卡 / 普卡 | 0.00 / ≤0.09 | 0.98 / 0.93~1.00 | 1 / 1~2 |

另一个坑是采样点：金取 2~6px 会越过框线进**卡面**（卡面也橙黄 S≈170），三档压成单峰；
彩卡反过来，光晕有厚度、bbox 会被撑大（致密度 0.69~0.88，甚至 0.41），
只读最外沿会漏。所以彩要**扫 bbox 内 0.8%~11% 的 9 圈取最浓的一圈**。详见 `docs/04` #73 / #74。

**MAX 标记不能当判据**：玩家原话「Max 不是一定有的」。实测 24 张普卡里 2 张带 MAX，
11 张彩卡里也有不带 MAX 的 —— 两者互不蕴含。

**器材怎么读**：**不靠 OCR**（卡面上只有插画/图标，没有可读文字），走图像 ——
「金边/高饱和掩膜 + 轮廓尺寸/致密度」找卡、「框线最外沿饱和度判金 + 多圈光晕色相判彩」。
读得出「几张 / 此刻是否在暴击」，读不出「是哪件器材」；上限 5 张。

## 3. 训练项读数（读数的时机）

- 点开训练项后 **0.4s 起拍、每 0.2s 一帧**，凑够 2 帧失败率 + 2 帧队友名就提前收工。
- 多帧投票（取众数）：防止 OCR 把「百目鬼」+「希雅」粘成「百希雅」。
- **整帧丢弃**的情况：
  - 不像训练项页（既没训练项名、也没失败率/Lv、场上名字 < 2 个）
  - 出现「赛前准备 / 跳过比赛 / 前往比赛 / MVP / 目标达成」← 说明中途切页了

## 8. 随机事件 / 剧情选项

**优先次序（🔒 与出行共用 `_reward_key`）**

| 位次 | 内容 |
|---|---|
| 4 | 笔记 |
| 3 | 技能 / 专属 / 绝技 |
| 2 | 精力（**按缺口截断**，超出上限的部分不算） |
| 1 | 属性 |
| 0 | 零用钱 / 其他 |

- 概率型奖励（「30% 概率 属性+60」）**不要** ✅ `event.reject_probability: true`
- 不能撤销的负面选项不选 ✅ `event.allow_negative_event`（在 plans 里）
- 纯对话没选项 → 点「跳过」

**竖排三选一怎么选**（`_rank_options`，2026-11-28 玩家：「按我们的优先级选，不是默认第一个」）

只有一份顺序，**没有「无数值另算」这回事**（那张「属性 > 精力」的表是我自己加的，
玩家当天否掉：「为什么属性大于精力？没道理」）：

| 情况 | 结果 |
|---|---|
| `精力恢复` / `属性上限` / `资金援助` | **精力**优先（未溢出时） |
| 精力已满（130/130） | 精力那档自动跳过 → **属性** |
| 有数值（`精力+70` / `属性+30`） | 同上，但精力按缺口截断：只差 21 时 +70 和 +30 都只吃 21，带属性的 +30 更值 |
| 一条都对不上（`等身垂耳兔玩偶` 这类物件名） | 位置：竖排最上、横排最右 |

同一页点了没反应（下一帧还停在这页）→ 降级到下一名，不会死磕第一选择。

## 9. 周末出行（✅ 部分 `trip`，多数 🔒）

- **笔记 > 训练**：从每日页进来只为看有没有笔记，有就出行、没有就回去训练（详见 §1）
- 地点优先级：**笔记 > 训练项 > 精力（未溢出）> 属性 > 零钱**
- 「精力未溢出」实现：`有效精力 = min(标签精力, 130 − 当前精力)`，缺口 21 时 +70 与 +30 打平，再比属性
- **「周日休息」= 去公园**（玩家 2026-11-23 明确）：
  周日不训练、去公园把精力补回来，下周一满血开局。
  公园子页兜底顺序也改成 **野餐 > 划船 > 散步**（`PARK_FALLBACK`）——
  原来读不到数值时会按地点顺序挑到「散步」，补得最少。
- ❌ 游戏厅（= 拼图小游戏）一律不去 ✅ `排除地点`

## 10. 商店（✅ `shop`）

**买什么：完全按 wiki 的训练流口径**（详见 `docs/12-商店采购清单.md`）

| 优先级 | 商品 | 效果 | 上限价 | 额外条件 |
|---|---|---|---|---|
| 1 | 老板的馈赠 / 馈赠+ | 零用钱 **+80**，标价 0 | ≤0 元 | 看到就白拿 |
| 1b | **任何标价 0 的商品** | 本次训练专属（「白神的笔记 / 训练手册」） | 0 元 | 白送必须拿，**不看名字认不认得** |
| 2 | 特训牛奶 | **减少训练精力消耗** = 多练一天 | ≤100 元 | — |
| 3 | 精力饮料（怪味/专属…） | 回精力（部分版为属性 +25~35） | ≤50 元 | **精力 <50** 才买；<35 时插到最前 |
| 4 | 器材暴击道具 | 暴击率↑（**带负面**） | ≤120 元 | **上一场器材上有人**才买 |
| 5 | 教科书 | 提升训练等级 | ≤120 元 | 只买金 |
| 6 | 属性秘籍 | 投射/弹跳/运控/体能/防守/意识 +X | ≤80 元 | 只买金；单项 >1200 收益减半 |
| 7 | 表情护符 +5% | 表情一致加成 | ≤80 元 | — |

**不买**：紫色/白色杂项、低品质效率等级书（wiki：性价比极低）、>50 元的回精力道具。

**入口**：① 精力 <50；② 商店图标挂着**「新品上市」**角标（= 上新了，不是按周算）。
这两条是**唯一**判据 —— 跟星期几无关（玩家 2026-11-28：「关星期几什么事啊」）。
每天最多进一次；一次最多买 4 件。**同一次进店，精力饮料 / 特训牛奶各自只买一件**
（买完顶栏精力不一定立刻刷新，旧值会让人以为还缺、重复买）。
**周日不进店**（去公园回精力，买药会溢出）——按你的要求，这条压过上面两条。

> 星期几只用来做两件事：按天记账、判「周日不进」。它**没有否决权**。
> 顶栏的「星期X」读丢时，记账键降级成 `第N周-?`（`_shop_day_key`），
> 精力/上新照判。旧代码把 `day is None` 当成「今天不进店」，
> 结果第 4 周星期一那帧只读到「第4周」，整天的上新被挡掉了（见 `docs/06`）。

进店先把货架**滚回顶部**，再逐屏往下扫到底，最后滚回顶部再点（见 `docs/19`）。
每次进店会存一张截图（`screenshots/auto/*_shop.png`），用来校准商品名。

**顺手记录**：这家店卖不卖精力道具 → 给「高风险改练意识」用。

## 10.5 周四抽奖 + 未知选项页（✅ 图形识别）

### 抽奖第一步：选店铺（`请选择要前往的店铺`）

实拍（`screenshots/auto/*_shop_choice.png`）：三家店横排，卡下标注 0/5/10，
选中的那张亮黄角标，底部一个黄色「确定」。**点完店不会自动走，必须再点确定**。

- 选哪家 → 后面转盘的内容不一样（玩家 2026-11-28）
- 规则：横排选**最右**
- **降级链**（玩家 2026-11-28）：右边点确定没反应 → 换中间点确定 → 再不行换左边点确定
  → 三家全失败才点右下角退出。状态机 `pick → confirm → verify`，
  `verify` 发现还停在选店铺页就 `_shop_try += 1`
- 以前这页被顶栏「第N周 星期X 精力」骗成每日页，在中心连点 15 步；现在判页排在每日页之前

### 抽奖页（`抽奖啦！` 技能转盘 / 周四抓娃娃）

玩家 2026-11-28 两次澄清：
1. 周四训练后的抽奖（抓娃娃）和技能转盘是两回事，但**逻辑一样**；
2. **「你点什么和转盘结果无关，可能要点一下进入下一页就是」**。

所以这页既不选、也不瞄准圆心，只做三件事：
1. 有明确按钮（转一转 / 抽一次 / 领取 / 确定 / 继续）→ 点它；
2. 读不到按钮 = 动画中 → **只等不点**（上限 8 步，每步 1.2s）；
3. 等太久 → 点右下角轻推，**绝不碰转盘中心**。

> 2026-11-28 踩坑：先是误判成三选一点了背景「电器」卡 15 步；

### 未知选项页（`_find_card_boxes`）

玩家 2026-11-28：「必须靠图形识别知道它有几个框、每个框在哪，不能靠文字，
因为每次随机事件不同角色，选项都不同」。

| 排列 | 选哪个 |
|---|---|
| 左中右（横排） | **最右边** |
| 上中下（竖排） | **最上面** |

做法（纯 OpenCV，不读文字）：

1. ROI = 画面中部 `x 0.10~0.90 / y 0.18~0.82`（避开顶栏、右上角图标、底部按钮）
2. Canny 边缘 → 9×9 闭运算把断边接成整框 → 找外轮廓
3. 过滤：面积占 ROI 1.2%~50%、宽高比 0.32~6、**四条边上真的有线**（`_frame_edge_score`）
4. 一排卡片常被边缘线连成大长条 → `_split_by_gaps()` 按内部暗缝切开
5. 按面积取中间那撮（同尺寸 ±35%）→ 要求**成行/成列且等距**（间距 max/min < 2.2）
6. 横排取 cx 最大、竖排取 cy 最小

离线验收：合成图 5 条（横三/竖三/横二/纯背景/零散按钮）全过；
`screenshots/auto` 248 张真实页面**误报 0**。

接入点：`_do_unknown`（未知页先试图形选项）、`_do_choice`（文字全空时）、
`_do_lottery_pick`（先图形后文字）、`_do_shop_pick`（店名读不到时）、`_do_event`（选项文字全空时）。

**降级链**（玩家 2026-11-28）：横排选项点最右没反应时，退到中间、再退到左边，
三家都失败才点右下角退出。`_do_shop_pick` 已实现（`pick → confirm → verify` 状态机）。
