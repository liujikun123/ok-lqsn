# 05 素材与证据

## 1. 录制素材（本项目最重要的资产）

| 项 | 值 |
|---|---|
| 目录 | `demo/session_1122_200929/`（原图在 `../ok-bsg/demo/session_1122_200929/frames/`，963 张 / 1.5G，未复制过来） |
| 时长 | 约 21 分钟 |
| 帧数 | 963 帧截图，541 个 screen 事件、422 个 click 事件 |
| 覆盖 | 第 1 周 ~ 第 7 周完整一段训练（大厅 → 训练 → … → 训练结束） |
| 文件 | `timeline.json`（全部 OCR 结果 + 点击坐标）、`summary.md`、`outline.md`、`digest.md` |

### timeline.json 结构

```json
{
  "events": [
    {"i": 5, "t": 7.12, "kind": "click", "img": "frames/005.png",
     "texts": [["训练剧本", 154, 50, 170, 47], ...],
     "click": {"x": 1639, "y": 943, "rx": 0.854, "ry": 0.873}}
  ]
}
```

- `texts` 每项 = `[文字, x, y, 宽, 高]`，坐标是**窗口内**像素（1920×1080）
- `click.x/y` 是**桌面**坐标（窗口有偏移时不能直接用）；`click.rx/ry` 是窗口内归一化坐标 —— **对齐必须用 rx/ry**
- `kind` 只有 `screen`（纯截图 OCR）和 `click`（点击时那一屏的 OCR）

## 4. 截图目录约定

| 目录 | 内容 |
|---|---|
| `screenshots/auto/` | AutoTask 每次关键决策的整屏截图（命名 `时分秒_tag.png`） |
| `screenshots/core_probe/` | CoreProbe 的每个技能整屏 + 卡片区放大图 |
| `screenshots/`（根） | 框架默认截图目录，每次重启会清空 |

> `screenshots_folder` 在 `src/config.py` 里配置；框架**每次重启会清空**根截图目录，重要证据要及时挪走。

## 5. 怎么重新分析素材

```bat
:: 1) 还原「哪一屏点了哪个按钮」
.venv\Scripts\python.exe tools\trace_flow.py > demo\flow.txt

:: 2) 卡片识别回归（不依赖游戏在跑）
.venv\Scripts\python.exe tools\detect_cards.py ..\ok-bsg\demo\session_1122_200929\frames\493.png

:: 3) 事件卡识别回归
.venv\Scripts\python.exe tools\test_event_cards.py
```

## 6. 环境重建（换了机器怎么办）

1. 装 Python 3.12（本项目用 `C:\Users\Administrator\py312`，版本必须 3.12，ok-script 要求 `>=3.12,<3.13`）
2. 建虚拟环境 → 装依赖：
   ```bat
   python -m venv .venv
   .venv\Scripts\python.exe -m pip install "ok-script[adb,default,ocr,qt]==3.0.0b3" openvino opencv-python
   ```
3. 首次跑 OCR 会自动下载 PP-OCRv6 模型（需要联网，约几百 MB）
4. 确认 `src/config.py` 里 `windows.exe = ['k3_windows_ob.exe']`、`capture_method` 首选 `WGC`、`interaction` 首选 `Pynput`、**没有 adb 键**

现在这套环境可以直接复用：`../ok-bsg/.venv`（`requirements.txt` / `pyproject.toml` 已随项目复制）。
