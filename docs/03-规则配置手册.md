# 03 规则配置手册

规则分两处：`config/strategy.yaml`（策略）和任务的 `default_config`（运行参数）。
本文逐项说明「玩家的哪句原话 → 落在哪个键 → 代码里在哪生效 → 现在到底生不生效」。

> ⚠️ 标记 ⚠️ 的项：**配置写了，但代码还是写死的**，改了不会生效。这是当前最该清理的技术债。
> 判断依据：`src/tasks/AutoTask.py` 里是否真的 `self.config.get(...)` 或 `_tuning()` 取过。

## 0. 先分清两种资源（搞混会全盘错）

玩家 2026-11-23 两次当面纠正，这是最容易想当然的一处：

| | 局内「精力」 | 局外「体力」（= 专注） |
|---|---|---|
| 上限 | **130**（每日页顶栏 ⚡ 38/130） | **150**，但**允许溢出**（实测见过 202/150） |
| 谁消耗 | 每次训练扣一次（实测 130→84→52→…） | **每次训练固定扣 30** |
| 怎么恢复 | **只有两条**：局内事件「精力+10」、周末「公园」（野餐 +70 / 划船 +30） | **只能用药水**（小瓶 +30 / 大瓶 +60） |
| 能不能用钻石 | 不涉及 | **绝对不买**，库存没了就关弹窗 |
| 在状态机里 | 驱动「今天训练还是休息」（`训练精力下限`=40） | 只当门槛，不参与训练/休息决策 |

代码判定靠**上限**当指纹（`_parse_ab`）：`b ≥ 145` → 体力；`40 ≤ b ≤ 140` → 精力。
不能靠位置 —— 两个数字都在顶栏，看 y 坐标会读反。

**体力允许溢出 `a > b`**，所以解析时不能写 `a <= b` 的校验，否则 202/150 会被整条丢掉；
OCR 吞掉斜杠时（`202150`）还要能还原成 202，而不是退化成 20。

**补药铁律**（因为一次训练只要 30）：体力 ≥ 30 就一滴不补，要补只喝小瓶 +30。

对应参数：

| 任务参数 | 默认 | 含义 |
|---|---|---|
| `训练精力下限` | 40 | 局内精力低于它就不练了（先出行/休息） |
| `专注恢复` | 用道具 | 局外体力不足时喝药水；`关闭` = 不喝 |
| `每轮最多补专注次数` | 4 | **每次弹窗**最多喝几瓶（弹窗关闭后自动归零重计） |

## 1. 训练项页 · 训练项打分（`tuning.core_score`）

**2026-11-23 三轮实机校正后的最终口径**（前两版都有错，以本表为准）：

| 键 | 值 | 含义 | 状态 |
|---|---|---|---|
| `teammate` | 1.0 | 场上每个角色 +1 分（**含球队经理、含主训本人**） | ✅ `_score_core` |
| `equipment` | 0.5 | 普通器材（白边/浅色）每张 0.5 分 | ✅ |
| `equipment_tier` | 普 0.5 / 金 1.0 / 彩 1.5 | 器材档位 = 局内熟练度触发的**暴击光效**（持续显示），暴击项收益更高 → 每张卡按档位计分 | ✅ |
| `level_bonus` | 全 0 | 训练项等级 **不参与计分**，只读出来打日志 | ✅ |
| `fail_weight` | 1.0 | 期望折算：`分 × (1 - 失败率/100)`，30% → ×0.7、50% → ×0.5 | ✅ |
| `fail_limit` | **30** | 玩家 2026-11-23：「失败可以赌一把，收益高的话 **<30 都能去**」→ 30 以内不排除、交给期望收益排；>30% 才踢出排名 | ✅ `_apply_fail_limit` |
| `log_gamble` | true | 选中带失败率的项时打一条「赌一把」日志，方便复盘这次赌对没有 | ✅ |
| `force_when_risky` | 见下 | 失败率全部 >30% 且商店无精力道具 → 改练「意识」 | ✅ |
| `resident_ratio` | 1.0 | 「每个训练项都在场」→ 认成本轮主训人员（只打日志、仍算队友） | ✅ `_main_char_of_round` |
| `main_char` | 闪堂 | **仅兜底备注**，代码不再用它剔人或计分 | ✅ 不参与 |
| ~~`ignore_names`~~ | **已删除** | 玩家 2026-11-23 确认：训练项页根本没有「替补/解说」这类标签，场上站着的都算队友（含经理、含主训本人） | — |
| `weekday_check_yellow` | true | 只点右上角带角标的技能 | ⚠️ 代码目前恒为「只点带角标的」 |

**器材到底在哪读**（这条曾被我判错两次，记牢）：

- 器材卡在**训练项页中场**，不点训练项之前就画在球场上，选中态一直保留，随时可读。
- 实机位置：x 0.32~0.44、y 0.54~0.73（1080p 约 150~220 × 140~210 px），最多三张横排。
- 检测：`src/core/cards.py` 的 `find_cards()` + `card_glow()`，金框掩膜 → 闭运算 → 轮廓，
  再按尺寸/长宽比过滤（**必须有尺寸上限**，否则会把「赛前准备」页的球队大卡当器材）。
- **不是每场都有**：室内体育馆那几轮实测 0 张，室外球场 1 张；所以「器材 0」不等于识别失败。
- 回归测试：`tools/test_equip.py`（65 张历史核心帧全 1 张金卡、赛前准备页无超尺寸误检）。

**主训人员怎么认**（玩家：「每轮训练你要知道主训人员是谁，不能写死名字」）：

- 判据 = 出现在**每个**训练项读数结果里的那个名字（`resident_ratio: 1.0`）。
- 认出来只写进日志「本轮主训人员：X」，**不从队友里剔除** —— 玩家同时要求经理算队友，
  而恒在场的名字对每个训练项都是 +1，排名不受影响；剔掉反而会因某帧 OCR 漏读少算一分。
- 实测两局：第 6 周认出「闪堂」，第 7 周换人后认出「希雅」，都没改代码。

```yaml
force_when_risky:
  enabled: true
  fail_over: 30      # 所有能练训练项的失败率都超过 30% 才算「高风险」
  skill: 意识        # 高风险时改练这个（本作成功率最高）
```

玩家的三条原话：

- 「等级不参与计分」
- 「当失败率高于 30，商店又没有精力道具卖的时候，选意识训练，成功率最高」
- 「球队经理和真崎是队友」「只点右上角带黄标的那几个」

**同分时**：比失败率，低者优先（代码里写死，合理，暂时不需要配置）。

**读数时机**：点开训练项后 0.4s 起、每 0.2s 一帧，凑够 2 帧失败率 + 2 帧名字就收工
（玩家 2026-11-23：「不用特定的时间窗口」—— 选中态会一直保留，不需要长窗口；
早先「先等 1.2s 再拍」那版拍到的是浮层收走后的空页面，实测 0/6 帧）。

**读数期间切页要丢帧**：10:32 实测读数中途弹到「赛前准备」，那一帧把阵容位置名
（分卫/大前/控卫）当队友、把球队大卡当器材，单项就刷出 8 分定案选错。
现在只要帧里出现「赛前准备 / 跳过比赛 / 前往比赛 / MVP / 目标达成」就整帧丢弃。

## 3. 周末出行（`tuning.trip`）

| 键 | 值 | 含义 | 状态 |
|---|---|---|---|
| `priority` | [笔记, 技能, 未溢出精力, 属性] | 见下方位次表 | ⚠️ 写死在 `_reward_key` |
| `exclude` / 任务参数 `排除地点` | 游戏厅 | 命中直接跳过（游戏厅=拼图小游戏） | ✅ 代码读**任务参数** |
| `park_first_fill_stamina` | true | 公园优先补精力 | ⚠️ 写死 |
| `fallback_order` | [公园, 散步, 野餐, 划船, 餐厅, 步行街] | 都读不到标签时的顺序 | ⚠️ 写死 |

玩家原话：「周六出行 笔记 > 训练」「周日 笔记 > 公园休息」「规则都没去游戏厅」

**当前实现（2026-11-23 06:45 重写）**：`_do_trip` / `_do_go` / `_score_option` 三处
统一走 `_reward_key(text)`，返回 `(tier, 有效精力, 属性, 零用钱)` 元组，字典序比较：

| 位次 | 内容 | 说明 |
|---|---|---|
| tier 4 | 笔记 | 最高优先，直接选 |
| tier 3 | 技能 / 专属 / 绝技 | 玩家 06:43 明确的第二档 |
| tier 2 | 能装进精力条的精力 | **超出上限的部分先截断**，见下 |
| tier 1 | 属性 | 精力吃不下时选它 |
| tier 0 | 零用钱 / 其他 | 兜底 |

**「未溢出」是什么意思**：玩家 06:43 实测发现，周日精力只差 21 点时脚本选了「精力+70」，
而同时存在「精力+30 且属性+」的选项 —— 那 49 点是白扔的。现在先把精力按缺口截断：

```
有效精力 = min(标签上的精力值, 130 - 当前精力)
```

于是缺口 21 时 `+70` 和 `+30` 的有效精力都是 21，**打平**，接着比属性 → 选「+30 属性+」；
缺口 100 时 `+70`(70) > `+30`(30)，仍然选 +70。这正是玩家要的行为。

`_gain()` 另外修了一处：OCR 常把数字吃掉只留「精力++」/「精力+」，原来一律返回 1，
三档全打平；现在按加号个数还原（单加 30 / 双加 70，属性 20/40）。

## 6. 商店（`tuning.shop`）

玩家 2026-11-23：「**商店具体的效果你去 wiki 看看，决定可以买哪些、长什么样**」。
完整查证过程与商品卡片外观见 `docs/12-商店采购清单.md`，这里只记配置。

**结论**：训练流只值得买 7 类 —— 0 元馈赠、特训牛奶、精力饮料（只买 50 以下）、
器材暴击（器材上有人才买）、教科书、属性秘籍、表情护符；紫白杂项和低品质效率书一律不买。

| 键 | 值 | 含义 | 状态 |
|---|---|---|---|
| 任务参数 `商店自动购买` | **true** | 总开关 | ✅ |
| `auto_buy` | true | 打开白名单购买（不是见啥买啥） | ✅ |
| `snapshot` | true | 每次进店存一张截图，方便校准商品名 | ✅ |
| `max_buy_per_run` | 4 | 一次进店最多买几件 | ✅ |
| `skip_weekdays` | **`[7]`** | 哪些星期几一律不进店（7=周日）。玩家 2026-11-23：「周日能逛公园回复，再去商店买精力药不就溢出了」 | ✅ `_want_shop` |
| `saturday_stamina_min` | 10 | 周六精力 ≥ 这个数就不买牛奶/精力饮料（玩家 2026-11-27：周日公园能补）；<10 见底才买 | ✅ `_shop_plan` |
| `keep_gold` | 120 | 买完金币仍要 ≥ 这个数；本轮笔记已拿到则为 0 | ✅ `notes_done` |
| `order` | free→milk→stamina→sway→manual→crit→book→stat→charm | 优先级顺序 | ✅ |
| `rules.free` | max_price 0 | 老板的馈赠：标价 0，零用钱 +80 | ✅ |
| `rules.milk` | max_price 100 / when_below 50 | 特训牛奶：降训练精力消耗；精力 <50 才买 | ✅ |
| `rules.stamina` | max_price 50 / when_below 50 / urgent_below 35 | 精力饮料：只买 50 以下；<35 见底时插到最前（同样受金币底线约束） | ✅ |
| `rules.sway` | max_price 130 | 摇摆专属饮料（两个推荐属性 +25~35，40/130 两档） | ✅ |
| `rules.manual` | max_price 100 | 器材手册（全部器材熟练度 +10） | ✅ |
| `rules.crit` | max_price 120 / need_equip true | 器材暴击：上一场器材上有人才买 | ✅ `last_equip_count` |
| `rules.book` | max_price 120 | 教科书（训练等级） | ✅ |
| `rules.stat` | max_price 80 | 属性秘籍 | ✅ |
| `rules.charm` | max_price 80 | 表情护符 +5% | ✅ |

**进店时机**（`_want_shop`）：精力 <50 **或** 换新的一周（商店「上新时间 7天后」= 一周才刷一次货）；
每天最多进一次，避免每日页 ↔ 商店来回打转。

**价格是纯数字**（130/40/50，不带「元」）—— 最早只认 `\d+元`，导致价格一直读成 None、
价格上限形同虚设。现在两种都认。

进商店时会顺手记录「这家店到底卖不卖精力道具」(`shop_has_stamina`)，训练项页那条
「失败率全 >30% 改练意识」要用它；本期没进过店就是 `None` → 那条规则不生效。
