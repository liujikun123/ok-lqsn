# 12 · 商店买什么（wiki 查证版）

> 玩家 2026-11-23：「商店具体的效果你去 wiki 看看，决定可以买哪些、长什么样」。
> 本文就是这次查证的结论，以及脚本落地成的白名单。
> 查证来源：《篮球少女：飞跃巅峰》训练流 / 四流派运营手册（GameKee、多篇同口径攻略）+ 实机商店截图 OCR。

## 1. 商店长什么样（实机截图 OCR 校对）

```
┌──────────────────────────────────────────────────────────┐
│  上新时间 7天后                                      [X]  │
│                                                          │
│  ┌──────────┐   ┌──────────┐   ┌──────────┐              │
│  │ 道具名 +  │   │ 道具名 ++ │   │ 道具名 +  │   ← 名字（+ 是强化等级）
│  │    0     │   │   130    │   │    40    │   ← 价格：**纯数字，不带「元」**
│  │  剩余:1  │   │  剩余:1   │   │  剩余:1  │   ← 库存
│  └──────────┘   └──────────┘   └──────────┘              │
│   零用钱+80      两个推荐属性随机+25~35      效果说明（在卡旁/卡下）│
│                                                          │
│  ┌──────────┐   ┌──────────┐   ┌──────────┐              │
│  │ 特训牛奶  │   │ 投射秘籍  │   │ 弹跳秘籍  │              │
│  │    50    │   │    60    │   │    60    │              │
│  └──────────┘   └──────────┘   └──────────┘              │
│                                                          │
│        比赛       │      商店      │     能力详情           │  ← 底部 tab
└──────────────────────────────────────────────────────────┘
```

要点：

- **每行 3 张卡，一页 6 张**，不滚动。
- 价格是**纯数字**（130 / 40 / 50 / 60），**不带「元」字** —— 这是最早踩的坑：
  代码只认 `\d+元`，所以价格永远读成 `None`，价格上限形同虚设。
- 名字后面的 `+` / `++` 是**强化等级**，不是品质。品质看卡片底色（金/紫/蓝）。
- 顶部「上新时间 N天后」只是倒计时文案；**真正判上新看商店图标上的「NEW」角标**
  （玩家 2026-11-27 纠正：不是一周一次），有角标就进店，没角标且精力不低就不进。
- 右上角 `[X]` 关闭；退出后回每日页。

## 2. 买什么（结论表）

wiki 对「训练流」（也就是本项目在玩的打法）的口径非常一致，逐条落到脚本：

| 商品 | 效果 | 典型价 | 买不买 | 脚本判据 |
|---|---|---|---|---|
| **老板的馈赠 / 馈赠+** | 零用钱 **+80**，标价 **0** | 0 | ✅ **看到就白拿** | 名字含「馈赠 / 红包」，且价格 ≤ 0 |
| **特训牛奶** | **减少训练精力消耗**（等于多练一天） | 50 | ✅ **优先级最高的付费品** | 名字含「牛奶 / 特训」，≤100 |
| **精力饮料**（怪味饮料 / XX专属饮料…） | 回精力；部分版是「推荐属性 +25~35」 | 40 | ✅ **只有精力 <50 时买，且只买 50 以下的** | 名字含「饮料 / 精力」；精力 <50；≤50 |
| **器材暴击道具** | 器材暴击率提升（**带负面效果**） | 90 上下 | ✅ 但**只有当天器材上站人才买** | 名字含「暴击」，≤120，且上一场采到 ≥1 件器材 |
| **金色教科书** | 提升训练等级 | 100+ | ✅ 只买金（紫/白不买） | 名字含「教科书 / 教材 / 等级书」，≤120 |
| **金色属性秘籍**（投射/弹跳/运控/体能/防守/意识） | 对应属性 +X | 60 | ✅ 只买金；单项属性 >1200 后收益减半 | 名字含「秘籍 / 属性书」，≤80 |
| **表情护符 +5%** | 表情一致加成 | 80 上下 | ✅ 有钱就买 | 名字含「护符 / 表情」，≤80 |
| **精力上限 +** | 提高精力上限 | — | ⚠️ 当属性书处理，不当精力药 | 名字含「精力上限」单独归类 |
| 紫色/白色杂项 | — | — | ❌ 不买 | 不在白名单 → 直接跳过 |
| 效率等级书（低品质） | 训练效率 | — | ❌ 不买（wiki：性价比极低） | 同上 |
| >50 元的回精力道具 | — | 130 | ❌ 不买（wiki：只买 50 以下） | 超上限直接跳过 |

**优先级顺序**（`shop.order`）：

```
0元馈赠  >  特训牛奶  >  精力饮料  >  器材暴击  >  教科书  >  属性秘籍  >  护符
```

例外：**精力 < 35（见底）时，精力饮料插到最前面** —— 今天练不动的话，
牛奶再划算也吃不到，先保命。

## 3. 为什么是这几样（wiki 原话）

- 「尽量保证训练日不休息……商店尽量只购买**精力药**，和**效率效果提升**，
  和**器材暴击**（只有当天有器材暴击并且上面站人时才买）的道具，
  尽量**不购买效率等级书，性价比极低**。」
- 「训练流商店刷新主要购买**教科书**（只买金色）、**属性书**（只买金色），
  **器材暴击道具**、**特训牛奶**（减少训练精力消耗）和**回精力道具**。」
- 「（商店流）**恢复精力的道具尽量只买 50 块以下的道具**。」
- 「比较适合选择的商店商品有**精力饮料、牛奶、器材暴击（有负面）、表情提升 5% 护符**等。」
- 「单项属性达到 **1200** 以后不要买该属性书籍，**属性获取会减半**。」

## 4. 脚本怎么执行（已实现）

| 环节 | 行为 |
|---|---|
| 进店时机 | **精力 <50** 或 **商店图标亮「NEW」角标（=上新）** → 每天最多进一次；周日一律不进 |
| 上新判定 | `_shop_new_badge()`：只认商店按钮**正上方且离得够近**（dy -3.2~-0.9 字高、dx ≤1.7 字高）的 NEW；一屏常有 2~3 个 NEW，商城那个离商店仅 80px |
| 读货架 | `_shop_offers()` 把 OCR 按名字分类 + 就近取价（支持纯数字价格） |
| 挑商品 | `_shop_plan()` 按 order 逐类过白名单，每类都可单独关 / 单独限价 |
| 精力药时机 | 牛奶和饮料都是**精力 <50 才买**；周六除非精力 <10，否则都不买（周日公园能补） |
| 花钱底线 | 看**买完**剩多少：`金币 - 价格 ≥ keep_gold`（默认留 120 给笔记，笔记买到后不再留） |
| 买几次 | **一次进店**最多 4 件（`max_buy_per_run`），买满就出店；下次上新照进，不因整轮买过而封门 |
| 存图 | 每次进店存一张 `screenshots/auto/*_shop.png`，方便后续校准商品名 |
| 副产物 | 记录「这家店卖不卖精力道具」→ 给「高风险改练意识」那条规则用 |

配置全在 `config/strategy.yaml` 的 `tuning.shop`：

```yaml
shop:
  auto_buy: true
  snapshot: true
  max_buy_per_run: 4
  keep_gold: 120
  skip_weekdays: [7]
  saturday_stamina_min: 10
  order: [free, milk, stamina, sway, manual, crit, book, stat, charm]
  rules:
    free:    {max_price: 0}
    milk:    {max_price: 100, when_below: 50}
    stamina: {max_price: 50, when_below: 50, urgent_below: 35}
    sway:    {enabled: true, max_price: 130}
    manual:  {enabled: true, max_price: 100}
    crit:    {max_price: 120, need_equip: true}
    book:    {max_price: 120}
    stat:    {max_price: 80}
    charm:   {max_price: 80}
```

## 5. 还没坐实的两件事

1. **每件道具回多少精力 / 加多少属性，wiki 上没有一致数值**，只有价格。
   所以脚本**不依赖具体数值**，只用「名字 + 价格 + 当前精力」判断 —— 数值变了也不会误判。
   等实跑时进了几次店、存下截图，再按真实货架把名字补精确（`SHOP_CATS` 里加关键词即可）。
2. **品质（金/紫）目前靠价格近似判断**，没做卡片底色检测。
   真要做到「只买金」，下一步按卡片外框颜色分档（`src/core/cards.py` 已有取框色的能力可复用）。
