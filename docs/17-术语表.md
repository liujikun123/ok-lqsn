## 二、「技能」这个词只有一个意思

**技能 = 游戏奖励的一种**，只出现在选项 / 奖励里，例如「获得技能」「获得精力」
「获得属性」。**六个训练项不再叫技能。**

选项优先级（玩家 2026-11-26 确认，代码里是 `strategy.yaml` 的出行/事件倾向）：

```
技能  ＞  未溢出的精力  ＞  属性  ＞  零用钱
```

注意「精力已溢出」时不给精力档加分，优先级会掉到属性之后。

## 三、其余常用词

| 标准名 | 含义 |
|---|---|
| 失败率 | 训练项详情里的 `失败率 N%`；>0 表示有概率失败，脚本会算期望分 |
| 角标 | 训练项条目右上角那个橙色小人圆点，代表「这一项有人站台」（队友数 > 0） |
| 主训人员 | 每个训练项都在场的那个人，每局会换，脚本从画面认，不写死 |
| 经理 | 场上支援之一，**按项概率出现**（实测 25.1%，跟普通支援同量级），不是常驻；权重 2.0 |
| 支援 | 训练项页场上站着的非主训角色（含经理）。按项概率出现，读到名字才计分 |
| 器材 | 开局选的支援卡（最多 5 个），训练中分布在各训练项、也可能不出现；卡上无文字，靠图像认「几张 + 品质」，读不出是哪件 |
| 器材品质 | 普（浅奶油黄细框，0.5）/ 金（浓橙金粗框 + 外光晕，1.0）/ 彩（紫粉彩虹光晕，1.5）。按**框线最外沿 1~3px** 的饱和度分：≥185 金、青蓝紫 ≥0.30 彩、其余普。实测占比 60% / 39% / 1% |
| 专注 | 局外体力（弹窗 a/150），只决定能不能开一次训练 |
| 精力 | 局内体力（顶栏 ⚡ a/130），训练消耗它，药水无效 |
| 评分 | 每轮训练结束那个 8000 / 9000 的数 |
